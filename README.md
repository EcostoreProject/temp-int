# Capteur de température intérieure

## Description

Mesure la temperature interieure avec un capteur DHT11, l'affiche sur un ecran LCD et transmet la valeur à un relais via un module XBee.

## Dépendances

* **DHT sensor library** - Version 1.4.7 - Adafruit
* **LiquidCrystal_I2C** - Version 2.0.0 - Martin Kubovčík, Frank de Brabander
